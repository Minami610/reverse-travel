## 絶対に守るルール（過去に実害が出たもの）

- **構文チェックが通っても画面は壊れる。描画不能が過去3回発生している。**
  フロントエンドやデータ形式を触ったら必ず `npm run verify-render`（初期描画＋検索後の状態まで検証）。
- **`npm run verify-render`（jsdom）には実レイアウトエンジンが無く、「要素の重なり」「見切れ」「他要素の裏に隠れる」は検出できない。**
  実際にこの種の見た目だけの不具合（0件画面のボタン見切れ、出発駅候補一覧が検索ボタン・地図の裏に隠れる）が2回続けて見落とされた（2026-10-07）。
  対策として`npm run verify-layout`（Playwright／Chromium）を常設した。0件の画面・候補一覧を開いた画面・結果のカード一覧・使い方の画面・検索ボタンが
  「この条件で検索」になった状態を、PC幅（1920×1080）・スマホ幅（390×844）の両方でスクリーンショットし、要素のbounding boxから重なり・見切れ・
